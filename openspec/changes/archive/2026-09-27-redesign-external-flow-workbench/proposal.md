## Why

The full frontend redesign still leaves external USD flows with dense permanent explanations, an unstructured editor and a wide identity-led table. History actions and asynchronous version reads do not locate their panels for keyboard users.

## What Changes

- Keep a short visible declaration/unreconciled notice and put full rules and reload-recovery caveat in native disclosure.
- Group entry fields and associate positive USD amount, explicit time-zone/coverage and half-open period guidance with controls.
- Lead period results with exact totals and economic columns, retaining full flow identity in keyboard-accessible disclosure and contained table scrolling.
- Focus the relevant heading for correction, void and version actions; return to the origin on cancel/close without late-response focus theft.
- Apply restrained responsive styling using current native React controls and local CSS.

## Capabilities

### New Capabilities
- `external-flow-workbench`: accessible external-flow entry, history navigation and responsive evidence.

### Modified Capabilities
None. Existing external-usd-flows financial/recovery/security contract is preserved.

## Impact

CapitalFlows.tsx/CSS and existing FLOW-004-A acceptance; retained FLOW-004-B recovery. No backend, API, migration, dependency or pipeline change. Depends on existing flow controllers and verified application shell; no data impact. Non-goals: whole portfolio/cash calculations, providers, other analytics/settings, production/preview rollout and final repository consolidation.
